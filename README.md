# STEP Odisha — Program Management Dashboard

A static analytics dashboard summarizing the **STEP Odisha_Program Management Sheet: 2026-27** Google Sheet — a 38-tab program tracker for Mantra4Change's Project-Based Learning (PBL) program with the Odisha School & Mass Education Department, OSEPA, and SCERT.

**This repo is public** — GitHub Pages on a private repo requires a paid GitHub plan, so the repo was made public to publish it. It surfaces internal staff task-ownership and real budget figures; be aware of that before sharing the link further.

## Viewing it

Live at: https://harsen-alt.github.io/step-odisha-dashboard/

Scoped to **Academic Year 2026-27 only** — prior-year (AY2024-25 / AY2025-26) comparisons have been dropped per program-team direction, and the school count uses the sheet's **24,000-school** "Outcome goal" figure rather than the smaller 1,184-school count tracked in the district-level tabs.

## What's covered

- AY2026-27 program scale (30 districts, 11 zones, 24,000 schools, 230 master trainers)
- Task status: main Project Tracker vs. the lesson-plan content pipeline
- Content-creation progress by grade (6-8), flagging the Grade 6 lag
- Rollout timeline: recent deadlines, what's due, and a logging gap since mid-June
- District-level tracking coverage across the top 10 (of 30) districts
- AY2026-27 budget: PBL Kit total, MT training budget, and the still-unbudgeted Teacher Training (Cascading) line — with a note on the 24,000 vs. 1,184-school basis discrepancy
- Task ownership by staff member, and a bus-factor flag
- Open risks and gaps pulled directly from the sheet

## A note on the school-count figure

The source sheet is internally inconsistent about program scale: the "Outcome goal" tab states ~24,000 schools, while three other tabs (district-wise tallies, the Zone/MT allocation table, and last year's actual reported spend) all tie to **1,184 schools**. This dashboard uses 24,000 per explicit program-team direction; the Budget section calls out where that changes the math (roughly 20×) so it can be reconciled before the figures are used externally.
